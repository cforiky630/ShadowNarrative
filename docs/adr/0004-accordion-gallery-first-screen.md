# 4. 首屏相册放弃斜轴采用手风琴画廊

- **状态**：已采纳 (Accepted)
- **日期**：2026-10-10
- **决策者**：产品与设计组
- **相关规格**：`docs/specs/16-ALBUM_SPACE.md §2.2`

## 背景与问题

最初规划的首屏相册为沿斜轴排布、由近及远退去的 3D 轴线排布。在实际体验与调优过程中，斜轴排布在视口留白、焦点无歧义识别及移动端友好度上均难以达到克制安静的审美预期。

## 决策

1. 首屏相册采用 React Bits 的 `AccordionGallery`（手风琴画廊）形态：一列并排展开，当前选中的一张满幅舒展，其余收拢为细条。
2. 保持精选与收藏优先展示规则（`albumService.getAlbumPhotos`）。
3. 移除了相册界面上的粒子效果，首屏纯净呈现照片实体本身，单张进入后才转入粒子态。

## 影响

- 视觉更加优雅沉浸，焦点清晰无歧义；
- 降低了首屏的 GPU 渲染负载，启动体验更轻快。
